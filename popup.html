Темный режим

Эта функция открывает настройки Chrome для включения встроенного темного режима для всех веб-страниц.

Как включить:

  1. Выберите "Enabled" в выпадающем списке
  2. Нажмите кнопку "Relaunch" внизу страницы

После перезапуска браузера все страницы будут отображаться в темном режиме.

Скачать видео

Инструкция по использованию:

Линия: Используйте переключатель для отображения/скрытия линии. Линию можно перемещать, перетаскивая ее за зеленую точку.

Ориентация: Нажмите кнопку "Изменить", чтобы переключить ориентацию линии между горизонтальной и вертикальной. После изменения линия будет отображаться по центру экрана.

Темный режим: Нажмите кнопку "Включить", чтобы открыть настройки Chrome для включения темного режима для всех веб-страниц.

Скачать видео: Нажмите кнопку "Скачать", чтобы скачать видео с текущей страницы. Если видео не найдено, появится окно для ввода URL.

Совет: Для определения черного цвета и засветов на видео используйте инструмент "Цветная пипетка".

Это расширение позволяет определить точный цвет любого пикселя на странице.
